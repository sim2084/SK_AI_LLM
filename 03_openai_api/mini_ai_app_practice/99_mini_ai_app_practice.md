# 미니 AI 앱 제작 실습

## 목표

지금까지 학습한 OpenAI API 기능을 활용하여 작은 AI 앱을 직접 설계하고 구현한다.

이번 실습의 목적은 지금까지 배운 기능을 하나의 앱 흐름으로 직접 조립해보는 것이다.

사용자 입력을 받고, AI가 처리한 결과를 화면에 보여주는 작은 서비스를 직접 만들어본다.


## 주제 선택

아래 주제 중 하나를 선택하여 구현한다.

1. AI 면접 준비 도우미 앱
2. AI 학습 퀴즈 생성기 앱
3. AI 뉴스/문서 요약 카드 앱

또는 위 주제를 참고하여 자신만의 주제로 변경해도 된다.


## 사용 기술

다음 기능 중 몇 가지를 골라 활용한다.

1. Responses API
2. Prompt Engineering
3. Structured Outputs
4. Streaming
5. Moderation
6. Embeddings
7. Function Calling
8. TTS
9. STT
10. 파일 저장


## 화면 기준

Streamlit으로 구현하며 다음 항목을 포함해야 한다.

1. 사용자 입력 화면
2. AI 응답 생성 기능
3. 결과 출력 화면
4. 최소 1개 이상의 선택 옵션
   - 예: 난이도, 말투, 문제 개수, 요약 방식 등
5. 생성 결과 저장 기능 또는 구조화된 출력 기능
